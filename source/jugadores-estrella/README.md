# Jugadores estrella — datos por archivo

Cada archivo corresponde a un jugador estrella (o par que se contrata junto) de [Nuffle Zone](https://nufflezone.com/jugadores-estrella-blood-bowl/).

Contenido típico: MV, FU, AG, PS, AR, coste, habilidades/rasgos, equipos para los que juega, reglas especiales (★).

Datos verificados contra [bloodbowlbase.ru — BB2025 Star Players](https://bloodbowlbase.ru/bb2025/starplayers/) (63 jugadores; enlace por jugador en cada archivo). Los marcados como **Megaestrella (MEGA-STAR)** lo indican en la línea *Categoría*. No figuran en bloodbowlbase: Bryce 'The Slice' Cambuel, Frank 'n' Stein y Prince Moranion.

Para el listado completo ver [source/index.md — Jugadores estrella](../index.md#jugadores-estrella).
