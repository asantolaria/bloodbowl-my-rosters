# FAQ y Errata (Designer's Commentary, mayo 2026)

Fuente: [bloodbowlbase — Latest FAQ (BB2025)](https://bloodbowlbase.ru/bb2025/core_rules/latest_faq/). Resumen de las entradas de reglas generales; las FAQ de habilidades concretas están integradas en [habilidades](../habilidades/README.md).

## Errata del reglamento

| Pág. | Tema | Cambio |
|------|------|--------|
| 33 | Modificar tiradas | Un D6 modificado **no puede superar 6**, pero **sí bajar de 1** (p. ej. Esquivar con -4 y sacar 2 = -2). |
| 35 | Cambio de turno | Un rival que acaba con el balón tras un **Pase o Entrega**, o interceptándolo, causa cambio de turno. |
| 122 | Rasgos | Un jugador **tumbado** puede declarar una **acción especial** de un rasgo activo si esta incluye un movimiento gratuito (p. ej. **Patada de despeje**, **Mirada hipnótica**). |
| 124 | Bola con cadena | El estado **Masticado** no impide su movimiento. |
| 155 | Capitán del equipo | Si el Capitán sale del roster, se nombra otro en el **prepartido del siguiente partido de liga**. |
| 165 | Renegados del Caos — Ogro | **Solitario (3+)** (antes 4+) y gana **Golpe mortífero**. |
| 167 | Enanos — Corredor | Añade **Agilidad (A)** a secundarias. |
| 172, 173, 180 | Humanos, Nobleza Imperial, Alianza del Viejo Mundo — Ogro | Quitar **Mutación (M)** de secundarias. |
| 180 | Alianza del Viejo Mundo | Halfling Hopeful **0-3**; Hombre Árbol de Altern gana **Solitario (4+)**. |
| 181 | Orcos — Goblin de línea | **PS 4+** (antes 3+). |

## FAQ de reglas generales

| Pregunta | Respuesta |
|----------|-----------|
| **Asegurar el balón:** ¿si un rival se acerca a 2 casillas tras declararla (p. ej. Perseguir)? | Se puede completar: la condición solo se comprueba al **declarar**. |
| ¿El clima Lluvioso afecta a **Asegurar el balón**? | **Sí** (-1). Los modificadores a chequeos de AG **no**, porque no es un chequeo de AG. |
| Acción especial (Apuñalar, Motosierra) en lugar del Placaje de una **Penetración**: ¿cuesta 1 MV? | **Sí**. |
| ¿Se puede contratar **Apotecario** después de empezar la liga? | **Sí**. |
| ¿Rerolls de equipo durante **¡A la carga!**? | **Sí**. |
| ¿Saltar varias veces en un turno? | **Sí**. |
| **Distraído:** ¿cuándo se quita? | Al activar al jugador, **antes** de declarar la acción (puede usar habilidades activas y declarar acciones especiales). |
| Orden al **Esquivar** contra Tentáculos/Placaje heroico/Perseguir | Elegir casilla → Tentáculos → mover → tirada de Esquivar (y rerolls) → Placaje heroico → si tiene éxito, Perseguir. |
| Despedir a un posicional: ¿puedo fichar otro en el mismo postpartido? | **No**: se contrata **antes** de despedir, así que no se puede superar el QTY. |
| Juego igualado: ¿límite de 4 Élite por habilidad o en total? | **Por habilidad** (4 Placar, 4 Esquivar…). |
| **Siempre hambriento** se come a un compañero: ¿cambio de turno? | Solo si el comido llevaba el balón. |
| **Luchador** / **Apartar** / **Placaje múltiple** en Penetración | **No**: se activan al declarar un Placaje. |
| Faltas: ¿puedo no añadir apoyos ofensivos (para evitar dobles con Furtivo)? | Sí, pero se decide **antes** de tirar. Los defensivos se aplican siempre. |
| **Equilibrio firme:** ¿anula el cambio de turno? | Sí: con 6 no se cae ni es derribado (sin Armadura ni cambio de turno). Se pueden usar Rerolls de equipo y tirar varias veces por turno. |
| **Capitán del equipo** con el Reroll de la **Mascota** | Compatible; cada uso de la Mascota exige su tirada de 4+. |
| ¿Sobornos si no puedo Protestar al árbitro? | **Sí**: se salta la protesta y se pasa al Soborno. |
| Grim Ironjaw (Furia + Placaje múltiple) | Si usa Placaje múltiple, ignora Furia en esos placajes. |
