# Alineaciones Blood Bowl (Markdown)

Alineaciones en Markdown (tablas estilo Nuffle Zone, 3ª temporada / BB2025). Para la descripción del repositorio y los **tiers NAF** usados en torneos, ver el [Inicio](../index.md).

## Nombre de los archivos

Al crear un roster nuevo, el agente debe usar la **plantilla** ([source/plantilla-roster.md](../source/plantilla-roster.md)) y guardar el archivo con este nombre:

**[nombre que le ha puesto el usuario al equipo] - [nombre del equipo/raza] - [valoración del equipo]**

En formato slug: minúsculas, guiones, sin acentos, extensión `.md`. Ejemplos:

- `barones-bigotudos-nobleza-imperial-1070k.md`
- `elven-thunders-union-elfica-1200k.md`
- `muertos-de-risa-no-muertos-1100k.md`
- `inicio-1000k-orcos-negros-1000k.md` (rosters en `iniciales/`)
